# GitHub交付说明

长期使命、授权、增量原则和版本规则以[AGENTS.md](../AGENTS.md)为准；本文件保留原GitHub-First协议的交付操作说明。旧协议中“每次全历史扫描、全量重训/克隆、九项完整报告、自动形成版本”等冲突解释已停用，既有公开版本及首次审查证据保持有效。

## 最小必要交付

1. 读取[唯一主要检查点与待办](../CHECKPOINT.md)，检查Git差异和现有远程归属，不重新初始化。
2. 修改相关工程或说明，运行受影响验证。文档/导航及交付工具调整复用已验收实验；数据、算法、合同、依赖或未知工程变更运行完整行为和集成检查。改变复现接口或依赖时补干净环境复现。
3. 检查新增公开材料、暂存差异、新提交和受影响许可。`scripts/audit_release.py --base <已审核祖先SHA>`审查工作树增量及该祖先之后每个提交的变更对象，能捕获新历史中已删除的内容；不扫描无关分支或未跟踪本地材料。独立候选/站点仍检查其实际文件。
4. 首次完整可达历史审查已保存于[公开交付记录](PUBLICATION_STATUS.md)。基线不明、扫描器/来源边界变化或出现历史风险时运行不带`--base`的全审查；无匹配不等于保密/权属证明，二进制须有摘要绑定的人工来源审查。
5. 更新必要说明和CHECKPOINT；日常提交/PR不生成Tag/Release，不自动改包版本。分支推送、相关CI通过后合入main，不强推或覆盖他人成果。
6. 核验公开仓库、精确main SHA、同SHA相关CI；启用Pages时核对HTTP与`site-provenance.json`来源SHA。未推送称本地进度；检查未完成则如实报告待验收。

## 实际验证范围

`.github/workflows/check.yml`检查变化路径；文档和维护工具变更不重训已验收研究。所有分支保留行为测试、发布候选/许可、静态站点和增量历史检查。风险源码、配置、依赖、未知路径或显式手动全量运行触发旧/新实验smoke、保存推理、字段工具及标签研究；手动全量亦检查全部可达历史。改动扫描器本身须另行复核其正确性与旧基线。

`scripts/build_pages.py`只复制已公开且实际运行的静态产物，记录源码SHA和文件摘要。专题说明可在GitHub阅读；页面中的工作台在浏览器运行本地JavaScript，训练与字段命令需要本地Python。Actions限标准公共Linux runner、短期Pages artifact，不申请新付费资源或缓存扩容。

`scripts/verify_publication.py`优先匿名API核验main与同提交CI；仅确认共享匿名额度耗尽时复用已授权CLI读取元数据，另以无凭据HTTP核验公开访问。权限错误仍阻断，验证来源如实记录。它验证指定提交的发布状态，不能代替研究验收。

## 证据、来源与报告

当前公开入口和历史首发证据见[PUBLICATION_STATUS](PUBLICATION_STATUS.md)，研究数值见[RC1_RESULTS](RC1_RESULTS.md)，当前待办只在[CHECKPOINT](../CHECKPOINT.md)维护。独立代码及合成数据MIT，依赖各自许可见[licenses](licenses.md)。私有状态和未审本地记录不进发布白名单。

日常报告只需改动、保持不变的成果、对应验证、提交/CI、相关限制。长期使命持续进行，但当前授权待办完成即可停止。自动恢复并未因本文件启用。
