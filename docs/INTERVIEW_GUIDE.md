# 五分钟演示与技术追问

环境安装不计入五分钟；先按README跑完或用已保存真实产物。打开 `demo/index.html`，无需外部服务。

| 时间 | 演示操作 | 必须解释的技术问题 |
| --- | --- | --- |
| 0:00–0:45 | 使命、架构；检索一个事件并打开关联实体 | 为什么独立合成；物理设备年龄一致性；同刻历史为什么排除 |
| 0:45–1:45 | 切模型选择窗/最终窗，看同容量森林与消融 | 标签成熟与冻结；AP/PR-AUC区别；为什么新增字段可能无益 |
| 1:45–2:45 | 完整候选、删条件、查看不稳定重新发现及失败种子 | 路径float32；训练填补；搜索后区间；固定候选与重新发现不同 |
| 2:45–3:30 | 改OR/AND或审核动作，重新回放并导出 | 逐事件动作差异；额外风险零拒绝；假设成本为什么不是业务收益 |
| 3:30–4:20 | 字段工具记录：未知工具失败、禁用、漂移 | 工具白名单与回滚；证据失效传播；为什么不能称LLM Agent |
| 4:20–5:00 | 选择性标签报告与命令复现 | 子集指标为何有偏；Recall识别区间；本人待掌握部分 |

## 可深入追问的实现入口

- SQL：`entity_windows.sql` 与 `sample.sql`。手写半开窗、可见时间谓词；说明多对一Rej→Pass不是误伤标签。
- 模型：`models.Transform`、`research_models.train_models`。解释训练拟合、缺失指示、选择阈值、最终标签隔离测试。
- 推理：`model_artifact.predict_json`。解释float32两次缩放舍入、树阈值精度、保存预测一致性与格式限制。
- Pattern：`models.complete_paths`、`patterns.complete_path_mask`。解释完整路径与人工简化，根叶常真为什么无区分力。
- 验证：`scripts/verify_v02.py` 不导入研究实现，独立复算指标、候选集合和策略；不意味着bootstrap机制及所有代理均已独立证明。
- 治理：`field_workflow.FieldWorkflow.execute`。说明白名单/验证/摘要链/错误恢复，不编造LLM调用。
- 识别：`label_visibility.identification_bounds`。用4行手算上下界，解释IPW positivity。

## 必须本人独立完成的练习（均未验收）

1. 不看AI解释，画一次决策时点的数据血缘，并复现一个1h边界反例。
2. 手算并实现AP、KS和有并列的Lift；解释为何不能从最终窗选择阈值。
3. 独立改一项特征族实验并先写研究假设；结果负向时写出替代解释。
4. 手动从CART抽取一条完整路径，逐ID核对；构造缺失、阈值与根叶边界。
5. 独立运行禁用→下游阻断→恢复仍保留禁令，定位一条工具错误记录。
6. 手算选择性缺失上下界，指出什么额外随机审计信息能缩窄边界。
7. 从新目录安装，修复一个失败测试；用自己语言解释未实现LLM与生产收益的原因。

AI完成开发不证明本人掌握。面试时应坦诚说明协作方式，并以现场解释、修改、反例与调试证明能力。

## 新增研究的五分钟深挖路线

1. **0—1分：外部信用数据卡。** 解释30000条观察来自哪里、CC BY 4.0、为什么不是支付误伤和OOT、重复特征组为何不是已验证客户。
2. **1—2分：四区模型比较。** 打开外部信用交互，比较LR/森林/HGB和配对AP区间；说明校准Brier反而略差，算法种子不等同独立验证。
3. **2—3分：完整规则到不稳定选择。** 展示328人完整候选、369人简化候选及12次重新发现；再看滚动窗Jaccard趋零，区分固定回放与重新发现。
4. **3—4分：标签与策略失败。** 切正常需求成本4/25，解释结论反转；展示未知风险相关延迟下IPW低估，指出不可识别所缺信息。
5. **4—5分：字段真实执行与反向审查。** 演示父字段禁用→子向量移除→旧报告失效；查看独立SQL参考、最终标签反转隔离测试和有界性能结果。

本轮最值得本人独立完成的三项练习（尚未验收）：

- **完整证据隔离：** 手写四区划分与训练内编码，反转最终标签，证明模型参数、候选和阈值不变而评价改变。
- **选择性标签识别：** 用十条手算样例解释联合可见概率、零覆盖和结果相关延迟，复算成本反转；不能把模拟真值带进选择。
- **治理与反例调试：** 不看AI解释，修改一个JSON字段单位、禁用其父字段，逐步定位缓存为何失效；独立修复一个SQL时间边界反例并保持全算一致。
