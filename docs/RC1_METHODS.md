# RC1 方法与解释边界

本轮在V0.2工程上修复真实缺陷，没有重新初始化。旧ZIP及旧结果是历史证据；新结果仅对应 persistent-device-v2 模拟器与0.3.0rc1源码指纹。

## 数据与时间

`generate.simulate`按物理device_id保存创建时刻，同ID年龄差严格等于决策时差/86400。linked_device_id是额外模拟关系，不等同原物理设备。风险生成是独立Bernoulli机制，审计标签延迟2—7天且理想化为全量可见；未知标签不填零。不存在真实企业阈值或字段字典。

`data.split_samples`明确实验起点、训练/选择半开窗及最终[95,120)天。训练标签在71天、选择标签在95天前成熟，最终审计至127天。边界外样本排除；非有限时间阻断。SQL窗口排除当前事件和同刻其他事件，仅计当时可见历史。来源/漂移诊断不是完全无混淆的证明。

## 比较与持久化

LR预处理只用训练拟合。Score/Raw/Hybrid/Enriched森林保持同容量；跨算法比较不是纯特征增益。完整速度输入消融同时移除原attempts_24h/declines_7d及新增WINDOW_FEATURES。prior_score仍可能编码相关信息，因此是条件输入删除，不是因果信息隔绝。

AP是阶梯PR面积，梯形PR-AUC另列；Lift按当前评价90百分位计算并披露并列覆盖。阈值和模型在选择窗冻结。后续时间窗和不同种子的模拟复现分别报告，均不能替代独立真实域验证。重采样区间按用户成簇，不提供所有模型/消融的同时显著性保证。

`model_artifact.py`把训练中位数、缺失映射、float32域、LR缩放/系数或每棵树结构与概率保存为JSON。在模型评价前从保存文件读回并核对选择窗预测；独立命令在源码外核对最终预测。推理仅支持本Lab二分类，不加载可执行对象，不声称通用模型格式或生产级服务。

## Pattern与策略

`patterns.py`保存完整模型路径；模型路径根叶常真与任意空用户AST严格分开。未分裂树可回放，但没有区分能力，不能晋升为有证据策略。冻结候选后才读最终标签，其他叶/删条件为说明性分析。金额/来源反证有共同支持限制，阈值敏感性不用于挑选最佳测试结果。

策略仅重算固定样本上的动作和假设成本；标签完全审计、拒绝防止全部风险损失、审核无保护、无行为响应均是模拟假设。不能识别上线收益或行为反事实。

## 字段工具与Agent

`field_workflow.py`真实调用白名单inventory/change/admission/restore工具，记录输入输出摘要、注册表前后摘要、链式记录和验证结果。未知工具失败保留状态，修正调用可继续；禁用/失效不会因restore复活；证据漂移与真实时间分别核验；点号容器键冲突阻断，说明文本无执行权限。

这是确定性工具工作流，没有LLM推理或自主语言规划。工具记录摘要不是身份签名。本地审核人字符串不是可信企业认证；新语义没有代本人批准。

## 选择性标签

`label_visibility.py`固定主实验已选模型，比较全量审计、非拒绝可见、仅成功支付、25%随机拒绝审计。子集AP/Recall只描述被观察人口。缺失结果构造二元标签的流行率与固定标记Recall sharp bounds；小样本穷举全部缺失赋值独立检验上下界。已知随机审计概率允许IPW比例估计，但有抽样误差；零概率的确定性缺失不能靠IPW解决。尚未实现选择性标签训练纠偏，未声称策略因果识别。

参考：[scikit-learn模型持久化](https://scikit-learn.org/1.6/model_persistence.html)、[AP定义](https://scikit-learn.org/1.6/modules/generated/sklearn.metrics.average_precision_score.html)。官方文档仅链接；本Lab JSON推理是独立实现的有限格式。
