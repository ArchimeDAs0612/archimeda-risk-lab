# 外部信用观测：协议与数据卡

本专题检验现有方法在外部观测约束下的表现。数据来自 I-Cheng Yeh 的 **Default of Credit Card Clients**，UCI，2009，数据 DOI [10.24432/C55S3H](https://doi.org/10.24432/C55S3H)。[官方数据页面](https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients)明确标注 **CC BY 4.0**；允许署名分享和改编。2026-10-18核对官方元数据与许可页面。本仓库仅发布独立实现、聚合统计及协议；原始CSV和逐条预测留在忽略的`runs/`，其数据许可不改成代码MIT许可。

## 任务合同

- 目标是已获信用卡客户的**次月违约标记**，Y=1；不是支付欺诈、拒绝误伤或反事实授信收益。原始研究为台湾客户，公开资料未给出概率抽样框、完整排除过程、拒绝申请人或机构子来源，不能外推到申请总体。
- 输入是2005年4—9月的历史账单、还款状态、付款额与额度。该历史月份属于同一行的预测变量，不能当成六个评价时间窗。次月标签晚于这些汇总记录，但逐条成熟时间和业务系统可得时间未提供；无法审计生产as-of延迟。
- ID只作记录键、排除出模型，不能假定相邻ID代表时间，也没有跨行主体关系可以证明主体隔离。相同23特征向量作保守重复组，确保它们不跨分区；这不是身份证明。
- 主要模型排除性别、教育、婚姻、年龄，保留性别和年龄作描述切片，不以切片指标证明公平性。还款状态作为类别处理，保留资料未完整解释的-2、0代码，不把它们任意改成缺失或线性逾期。
- 没有独立历史风险评分，`status_only`是六个月还款状态基线，不命名为Score-only。负账单额与0金额不擅自删去。质量报告保存重复、冲突标签和未文档化类别。

## 冻结设计

[协议](../config/credit_protocol.json)在训练前保存；按不含标签的特征指纹划分60%训练、10%校准、10%选择、20%最终评价。输入预处理只拟合训练；sigmoid只用校准区；选择区决定三种全金融输入模型的赢家、规则和阈值。最终区只评价冻结方案，复现重跑不叫新的盲测。

LR沿用现有实现，并与sklearn原生概率输出对照；随机森林与直方图梯度提升用现有锁定的sklearn 1.6.1，单线程。三种全金融输入模型各三种子用于算法波动；主要种子下有还款状态、账单、付款族消融，不进行无目的调参。比较AP（sklearn average_precision_score）、AUC、KS、单独标注的梯形PR面积、Brier及开发集10%分位冻结阈值的审核量。阈值迁移后的最终审核率可能不是10%，必须报告实际值。

配对AP区间按相同特征组重抽样，保留预测成对关系；该区间条件于固定训练与观察队列，不能证明跨时间或新机构泛化。三种子不是三个新总体。

Pattern使用训练生长的深度3树，选择区支持量至少100，按Wilson下界排序，所有候选公开。完整路径与sklearn叶成员逐分区精确核对；删除最后条件成为新规则，单独重算支持量；金额阈值±训练SD的5%只作预登记敏感性。12次训练组bootstrap重新发现只衡量选择稳定性，固定规则分区迁移另列。额度下调25%是机制压力场景，不是真实OOT。

校准另有独立开发子区；决策成本比2/5/10是明示的研究假设，阈值只在选择区101点网格中选择。不能把违约标签乘成本当作实际催收/拒绝策略因果收益。

## 运行入口

```bash
python scripts/fetch_credit_data.py --out runs/credit-input/uci350.csv
python -m risklab credit-study --data runs/credit-input/uci350.csv --config config/credit_protocol.json --out runs/credit-study
```

输出包括冻结协议、数据质量、分区指纹、冻结选择、聚合结果和本地逐行预测。已有输出目录不可覆盖。网络源改变校验值时失败关闭，先审查数据差异，不能自动接受新数据以获得更好结果。

本人练习：解释为何月份列不是OOT；手算一个完整路径并比较简化后的成员；解释配对抽样区间与多种子波动的区别。本次工程运行不代表本人已独立掌握。

## 已运行结果与失败记录

最终评价6045条、1353个违约。全金融输入的LR AP0.531061、森林0.547554、HGB0.562487；HGB对LR配对AP差0.031426，300次相同特征组重抽样95%区间[0.017562,0.045012]。移除还款状态后HGB AP降至0.45734，而移除账单或付款族仅小幅下降；这是条件于其余相关输入的消融，不是因果贡献。

三种子中LR/HGB结果相同，因为当前求解和小样本HGB设置没有实际随机子采样；不能将相同结果冒充独立泛化。森林三种子AP在0.54589—0.54755之间。sigmoid Brier由0.13474265变为0.13475517，略差；单调校准不改变排序和固定容量的选中集合。开发阈值在最终区覆盖10.57%，另有固定floor(N×10%)且同分按记录ID打破的精确容量结果。

首次运行在macOS密集矩阵运算中出现浮点警告，按-W error中止。改用liblinear拟合sigmoid、用sklearn稀疏输入概率作为独立参考，不关闭浮点警告；完整重新运行后概率误差在浮点容差内。新增容量指标的复现中，全部既有模型和Pattern结果精确一致。此次维护未根据最终区重新选择模型或规则。
